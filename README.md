# Buildans Gas Suppliers - Prototype

Live URL: https://buildans-gas-proto.vercel.app

Mobile-first PWA prototype for Buildans Gas Suppliers (LPG delivery in Thika, Kenya).

## Features
- Home page with estate selector and quick order actions
- LPG configurator (refill vs new set, size, brand, upgrades)
- Checkout with phone/address validation and payment method selection
- Order tracking with rider details and EPRA safety guidelines
- WhatsApp/call CTAs using client number +254714899200
- Responsive mobile-first design

## Tech
Next.js 15 (App Router), TypeScript, Tailwind CSS v4
